# Cover images

Upload PNG cover images directly into this folder on GitHub. No Excel edits or code changes are needed.

Name each PNG using the tool's **id** column, in lowercase, followed by `.png` (not its full display name). For example:

- Clipchamp → `clipchamp.png`
- DaVinci Resolve → `davinci-resolve.png`
- OBS Studio → `obs-studio.png`
- Adobe Photoshop → `adobe-photoshop.png`

Recommended size: 1280 × 720 pixels (16:9), ideally under 500 KB. Other sizes work but are cropped to fill the cover area; keep important content near the centre. Use opaque backgrounds for the most predictable results. Use only images you have permission to publish.

1. Open `covers` in the GitHub repository.
2. Choose Add file → Upload files.
3. Upload the PNGs and commit to main (or merge your changes into main).
4. Wait for the normal Pages workflow to complete, then reload the site.

The same image appears on the tool card and the detail panel. Missing or unreadable images are removed automatically, leaving the original layout. Upload a new image with the same filename to replace it; delete it to return to the original card. Capitalisation matters: `Canva.PNG` will not match `canva.png`. Keep a stable tool id when renaming the display name.

For local previews copy images into this covers folder and reload index.html. On the deployed site, changes become available after the GitHub workflow finishes. If replacing an image seems not to work, hard-refresh with Ctrl+F5.
